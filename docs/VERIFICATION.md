# Preparation verification

Performed here:
- Extracted source materials and inspected main-paper, supplement and experimental-table contents.
- Counted complete, finite eight-column measurements, checked exact row uniqueness and excluded formatted blank rows from counts.
- Matched all 300 supplied preselected measurements against raw-sheet records; confirmed all 300 match the corresponding same-name raw plane.
- Confirmed copied source materials are byte-identical with SHA-256.
- Generated the nominal-kinematics measurement view from real joint configurations; transcribed published table values with source/status columns.
- Checked local Markdown/image links and ZIP integrity and individual-file sizes.

Not performed here:
- MATLAB execution, DE search, calibration convergence or rerunning the 9-method paper benchmark.
- Physical robot compensation or remeasurement.
- MATLAB finite-difference test execution. The included check must be run locally.

The preparation environment has no MATLAB or GNU Octave executable. Data preparation checks must not be described as passing solver tests.
